# 🚨 HazAlert

> A real-time hazmat evacuation dashboard that answers one question for any resident, in any language: **"Am I safe, and what do I do right now?"**

Built for the **CTC × Google Gemini Prompt-a-Thon 2026** at UC Irvine.

---

## 🎯 The Problem

On May 21, 2026, a chemical tank at the GKN Aerospace facility in Garden Grove, California began leaking methyl methacrylate (MMA). Over 50,000 residents across nine square miles were evacuated. Information was scattered across city websites, fire authority feeds, news stations, school alerts, and social media — leaving the most vulnerable residents (non-English speakers, elderly, disabled) the most at risk.

HazAlert solves this with one consolidated, accessible, multilingual dashboard.

---

## ✨ Features

- 📍 **Address / ZIP / Geolocation lookup** — instant zone status check
- 🗺️ **Interactive Google Map** — evacuation zones, your location, shelters, routes
- 🚨 **4-state status card** — Mandatory / Shelter-in-Place / Watch / Safe
- 🚗 **Fastest safe evacuation route** — avoids plume drift direction
- ✅ **Personalized checklist** — generated by Gemini based on your household
- 🤖 **Gemini-powered chatbot** — plain-language answers to any question
- 🔊 **Voice mode** — Google Cloud TTS reads everything aloud
- 🌐 **5-language support** — English, Spanish, Vietnamese, Korean, Tagalog
- ♿ **WCAG AA compliant** — high contrast, screen reader friendly, keyboard navigable

## 🚀 Running Locally

```bash
git clone https://github.com/[YOUR-USERNAME]/hazalert.git
cd hazalert
npm install
```

Create a `.env` file with your Google API keys:

```
VITE_GOOGLE_MAPS_API_KEY=your_key_here
VITE_GEMINI_API_KEY=your_key_here
VITE_GOOGLE_CLOUD_API_KEY=your_key_here
```

Run the dev server:

```bash
npm run dev
```

Open `http://localhost:5173`
